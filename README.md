# «Эхо Разлома» (Echo of the Rift) — v1.7

**Браузерная 3D action-RPG**, соединяющая механики шести великих RPG в одном мире:

| Домен | Эхо | Механика |
|---|---|---|
| Вельд | The Witcher 3 | контракты, следопытство, масла и зелья, бестиарий |
| Гранитная Долина | Gothic 2 | тренировки у мастеров (LP), фракции-карьеры, ямные бои |
| Стылое Пределье | Skyrim | Ту'ум-крики, рунная головоломка, дракон-событие |
| Багровая Мара | Dragon Age: Origins | оборона бастиона волнами, приказы, мор-погода |
| Спорные Земли | Baldur's Gate 3 | d20-проверки с кубиком, выборы, меняющие ландшафт |
| Сердце Разлома | Mass Effect 2 | рейд-финал с ролями, суд Пожирателя, 5 концовок |

> Полный дизайн-документ — в [`docs/GDD/`](docs/GDD/) (**v2.0, 10 документов**: видение, лор, механики, мир, архитектура, роадмап, UI/UX, контент, QA-ворота G0–G8, глоссарий) + PDF-книга `docs/GDD-Echo-of-the-Rift-v2.0.pdf`.

## Технологии

- **Next.js 16** (App Router) + **TypeScript 5**
- **Three.js** (WebGL2) — 3D-рендер: террейн-чанки, сутки/туман/атмосферы доменов, кинокамера диалогов, изометрия тактической паузы
- **Zustand** — мост движок ⇄ React-UI
- **WebAudio** — процедурный SFX-синтезатор (20+ звуков), голоса доменов (эмбиент) и **адаптивный музыкальный директор** (слои explore/combat, кроссфейд 2 с, lowpass в тактической паузе, стингеры событий)
- **shadcn/ui + Tailwind 4** — интерфейсы

## Запуск

```bash
bun install
bun run dev        # http://localhost:3000
bun run lint       # ESLint
bunx tsc --noEmit  # typecheck
```

## Управление (в игре)

`WASD` / `ЛКМ` — движение · `ПКМ` (зажать) — камера, колесо — зум · `ЛКМ по врагу` — цель · `1–7` — умения · `R/T` — крики · `Space` — тактическая пауза и приказы · `V` — строй отряда · `Tab` — цель · `Q/E` — зелья · `F` — взаимодействие · `C/I/J/M` — персонаж/инвентарь/журнал/карта · `Esc` — меню и настройки

## Настройки (Фаза 8)

- **Графика:** режим 3D/legacy-2D, пресеты качества «Низкое/Среднее/Высокое/Авто» (pixelRatio + тени), живой FPS-метр.
- **Авто-даунгрейд:** в режиме «Авто» пресет снижается при среднем FPS < 42 и возвращается при стабильном > 55 (GDD 06 §7).
- **Звук:** отдельные ползунки музыка / эффекты / эмбиент + общий mute; всё сохраняется в localStorage.

## Структура проекта

```
src/app/page.tsx            — единственный маршрут (титул ⇄ игра)
src/components/game/        — HUD, панели (персонаж/инвентарь/журнал/карта/настройки/титры), диалоги
src/lib/game/
  engine.ts                 — движок-фасад (публичный API для UI)
  core/                     — GameLoop, порядок систем, EngineCtx, утилиты
  systems/                  — бой, ИИ, движение, квесты, диалоги, сейвы, домены, финал, uiSync
  data/                     — контент: мир, квесты, диалоги, домены, финал, таблицы баланса
  render2d/                 — легаси-рендер и миникарта
  render3d/                 — Three.js: террейн, пропсы, аватары, FX, атмосфера
  audio/MusicDirector.ts    — адаптивная музыка + темы боссов по фазам HP (GDD 04 §4.1/§4.3)
  voice.ts                  — озвучка ключевых реплик (TTS через /api/tts, 2 голоса)
  bindings.ts               — ремап клавиш (localStorage, русская раскладка)
  sfx.ts / settings.ts      — SFX-синтезатор с шинами громкости / настройки (вкл. озвучку)
docs/GDD/                   — пакет дизайн-документов v2.0 (10 частей)
worklog.md                  — журнал работ агентов (фазы 0–8)
```
