# «Эхо Разлома» (Echo of the Rift)

**Браузерная 3D action-RPG**, соединяющая механики шести великих RPG в одном мире:

| Домен | Эхо | Механика |
|---|---|---|
| Вельд | The Witcher 3 | контракты, следопытство, алхимия |
| Гранитная Долина | Gothic 2 | тренировки у мастеров (LP), фракции-карьеры |
| Стылое Пределье | Skyrim | исследование, Слова (Крики), гильдии |
| Багровая Мара | Dragon Age: Origins | партия, тактическая пауза, приказы |
| Спорные Земли | Baldur's Gate 3 | d20-проверки, выборы с последствиями |
| Внешняя Рубежа | Mass Effect 2 | миссии лояльности, финальный рейд |

> Полный дизайн-документ — в [`docs/GDD/`](docs/GDD/): концепция, мир и сюжет, механики, архитектура, арт, дорожная карта.

## Технологии

- **Next.js 16** (App Router) + **TypeScript 5**
- **Three.js** (WebGL2) — 3D-рендер (переход с canvas-2D по плану GDD 03)
- **Zustand** — мост движок ⇄ React-UI
- **WebAudio** — процедурный звук
- **shadcn/ui + Tailwind 4** — интерфейсы

## Запуск

```bash
bun install
bun run dev        # http://localhost:3000
bun run lint       # ESLint
bunx tsc --noEmit  # typecheck
```

## Управление (в игре)

`WASD` — движение · мышь — камера/цели · `1–7` — умения · `Space` — тактическая пауза · `Q` — приказ отряду · `E/F` — взаимодействие · `C/I/J/M` — персонаж/инвентарь/журнал/карта · `Esc` — меню

## Структура проекта

```
src/app/page.tsx          — единственный маршрут (титул ⇄ игра)
src/components/game/      — HUD, панели, диалоги (React-оверлеи)
src/lib/game/
  engine.ts               — движок (фасад; декомпозируется по GDD 03 §5)
  render.ts               — canvas-2D рендер (легаси, → render3d/)
  data/                   — контент: предметы, умения, квесты, диалоги, мир
  store.ts / types.ts     — UI-зеркало + доменные типы
docs/GDD/                 — пакет дизайн-документов (5 частей)
worklog.md                — журнал работ агентов
```

## Статус

- ✅ Играбельный прототип (2D-канвас): полный цикл «титул → квесты → отряд → фракции → тренировки → босс → эпилог», сейвы, d20-бой, знаки, бестиарий.
- ✅ GDD-пакет для перехода на полноценный 3D.
- 🚧 Фаза 0: модульный рефакторинг движка (план: `docs/GDD/03-architecture.md`).
- 🚧 Фаза 1: 3D-ядро (Three.js, третье лицо, чанковый террейн).

## Лицензия

Игровой код и материалы — собственность команды проекта. Названия игр-источников принадлежат их правообладателям; проект не использует защищённый контент, только оммажи механиками.
