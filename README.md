# «Эхо Разлома» (Echo of the Rift) — v2.3

**Браузерная 3D action-RPG**, соединяющая механики шести великих RPG в одном мире:

| Домен | Эхо | Механика |
|---|---|---|
| Вельд | The Witcher 3 | контракты, следопытство, масла и зелья, бестиарий |
| Гранитная Долина | Gothic 2 | тренировки у мастеров (LP), фракции-карьеры, ямные бои |
| Стылое Пределье | Skyrim | Ту'ум-крики, рунная головоломка, дракон-событие |
| Багровая Мара | Dragon Age: Origins | оборона бастиона волнами, приказы, мор-погода |
| Спорные Земли | Baldur's Gate 3 | d20-проверки с кубиком, выборы, меняющие ландшафт |
| Сердце Разлома | Mass Effect 2 | рейд-финал с ролями, суд Пожирателя, 5 концовок |

> Полный дизайн-документ — в [`docs/GDD/`](docs/GDD/) (**v2.3, 10 документов**: видение, лор, механики, мир, архитектура, роадмап, UI/UX, контент, QA-ворота G0–G8, глоссарий) + PDF-книга `docs/GDD-Echo-of-the-Rift-v2.0.pdf` (актуален v2.0; v2.1+ — см. GDD 06).

## Технологии

- **Next.js 16** (App Router) + **TypeScript 5**
- **Three.js** (WebGL2) — 3D-рендер: террейн-чанки, сутки/туман/атмосферы доменов, кинокамера диалогов, изометрия тактической паузы
- **Zustand** — мост движок ⇄ React-UI
- **WebAudio** — процедурный SFX-синтезатор (20+ звуков), голоса доменов (эмбиент) и **адаптивный музыкальный директор** (слои explore/combat, кроссфейд 2 с, lowpass в тактической паузе, стингеры событий)
- **shadcn/ui + Tailwind 4** — интерфейсы

## Производительность (v2.1 — зоны-сцены; v2.2 — мобильный пресет; v2.3 — мобильный комфорт)

Мир больше не одна огромная сцена: **каждая земля — отдельная сцена-локация**, переход через врата (порталы) пересобирает рендер и симуляцию. Рендерится и просчитывается только текущая зона:

- **3D:** террен-чанки и инстансинг пропсов только по прямоугольнику зоны; камера `far` и туман — под её размер; MSAA отключается при devicePixelRatio ≥ 2.5; капы pixelRatio снижены (low 1.0 / medium 1.25 / high 1.75).
- **2D (legacy):** терен запекается по зоне в масштабе 0.5 (LRU-кэш на 2 зоны) вместо канваса 8800×4200 (~148 МБ VRAM); блит только видимого прямоугольника; culling пропсов/сущностей по камере; виньетка кэшируется.
- **Симуляция:** сущности (НПС/враги) существуют только в текущей зоне; шаг симуляции зоны — доли миллисекунды.
- **Карта/миникарта:** показывают текущую землю и её врата; прочие земли — «за вратами».
- **Полный экран (v2.2):** кнопка на титуле, постоянная кнопка у шторки меню и в самой шторке; на телефоне игра сама разворачивается в полный экран при старте (клик «Начать путь» — user-жест), в ландшафте фиксируется ориентация; канвас корректно ресайзится на fullscreen/поворот/коллапс адресной строки (`h-dvh`; на iOS Safari кнопка скрыта — API недоступен).
- **Мобильный HUD (пересмотр v2.1 + фиксы v2.2):** меню — шторка сверху (≥44px, скроллится на низких экранах, пункты не сплющиваются), нижние углы целиком отданы джойстику и кластеру действий; кластер показывает только открытые умения и не наезжает на миникарту/трекер (E2E-ассерт прямоугольников на 640×360); трекер квеста свёрнут в строку; карточка игрока шире — имя не обрезается; FPS-чип показывает текущий FPS и пресет.
- **Пресет «Мобильное» (v2.2):** pixelRatio 0.85, без теней и MSAA, дальность ×0.55 + туман ×1.3, снег урезан, **кап 30 FPS** (скип кадров без потери симуляции) — цель ≥30 FPS на телефонах класса Realme 13 5G; «Авто» на сенсорных устройствах доезжает до него само (десктоп — до «Низкого»).
- **Небо без «чёрной дыры» (v2.3):** купол неба масштабируется под текущую дальность камеры (на «Мобильном» far ~1300–2600 меньше радиуса сферы — дальняя плоскость отсекала верх купола, над горизонтом висел чёрный сектор); depth-тест у неба выключен — рисуется всегда целиком, первым в кадре.
- **Тапы — только в тактике (v2.3):** на сенсоре в реалтайме клики по миру отключены (движение — только джойстиком; тапы «срабатывали когда не нужно»); в тактической паузе тап по-прежнему приказывает отряду (компаньон/земля/враг). Мышь не затронута.
- **Панели и диалоги на таче — полный экран без прозрачности (v2.3):** журнал/инвентарь/карта/персонаж/настройки/концовка и диалоги разворачиваются на весь экран непрозрачным полотном, а мир за ними **не рендерится вовсе** (`renderSuspended` — GPU и батарея отдыхают, пока игрок читает); музыка продолжает тикать.
- **Логи по краю (v2.3):** инфо-тосты переехали из центра влево и стали компактными (стиль «Ведьмак 3»: тонкая цветная полоска, без крестиков, автоудаление) — не заслоняют обзор и плашку зоны.
- **Интеракт-подсказка на таче (v2.3):** вместо мелкого текста «… — [F]» — крупная кликабельная карточка с иконкой руки у кластера действий; клавиатурные ключи из текста на сенсоре убраны.
- **Обучение (v2.3):** контекстные подсказки для новичка — движение, интеракт, диалоги, журнал, бой, тактические приказы, меню; тексты для тача и клавиатуры, RU/EN, прогресс в localStorage, крестик закрывает шаг навсегда.
- **Русская озвучка (v2.3):** диалоги и боевые барки говорит системный голос устройства (Web Speech API, ru-RU на русской локали — настоящий русский TTS телефона, мгновенно и без сети); прежний бэкенд-TTS (голоса SDK) остался фолбэком, если системного голоса нет.

## Запуск

```bash
bun install
bun run dev        # http://localhost:3000
bun run lint       # ESLint
bunx tsc --noEmit  # typecheck
```

## Управление (в игре)

`WASD` / `ЛКМ` — движение · `ПКМ` (зажать) — камера, колесо — зум · `ЛКМ по врагу` — цель · `1–7` — умения · `R/T` — крики · `Space` — тактическая пауза и приказы · `V` — строй отряда · `Tab` — цель · `Q/E` — зелья · `F` — взаимодействие · `C/I/J/M` — персонаж/инвентарь/журнал/карта · `Esc` — меню и настройки

## Настройки (Фаза 8)

- **Графика:** режим 3D/legacy-2D, пресеты качества «Низкое/Среднее/Высокое/Авто» (pixelRatio + тени), живой FPS-метр.
- **Авто-даунгрейд:** в режиме «Авто» пресет снижается при среднем FPS < 42 и возвращается при стабильном > 55 (GDD 06 §7).
- **Звук:** отдельные ползунки музыка / эффекты / эмбиент + общий mute; всё сохраняется в localStorage.

## Структура проекта

```
src/app/page.tsx            — единственный маршрут (титул ⇄ игра)
src/components/game/        — HUD, панели (персонаж/инвентарь/журнал/карта/настройки/титры), диалоги
src/lib/game/
  engine.ts                 — движок-фасад (публичный API для UI)
  core/                     — GameLoop, порядок систем, EngineCtx, утилиты
  systems/                  — бой, ИИ, движение, квесты, диалоги, сейвы, домены, финал, uiSync
  data/                     — контент: мир, квесты, диалоги, домены, финал, таблицы баланса
  render2d/                 — легаси-рендер и миникарта
  render3d/                 — Three.js: террейн, пропсы, аватары, FX, атмосфера
  audio/MusicDirector.ts    — адаптивная музыка + темы боссов по фазам HP (GDD 04 §4.1/§4.3)
  voice.ts                  — озвучка ключевых реплик (TTS через /api/tts, 2 голоса)
  bindings.ts               — ремап клавиш (localStorage, русская раскладка)
  sfx.ts / settings.ts      — SFX-синтезатор с шинами громкости / настройки (вкл. озвучку)
docs/GDD/                   — пакет дизайн-документов v2.0 (10 частей)
worklog.md                  — журнал работ агентов (фазы 0–8)
```
