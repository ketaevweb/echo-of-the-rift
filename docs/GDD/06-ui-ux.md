# GDD 06 — UI/UX: экраны, HUD и пользовательские флоу

> Пакет GDD «Эхо Разлома» · Документ 6 из 9 · Палитры и токены — GDD 04 §3

---

## 1. Принципы UX

1. **Бой читается за 0.5 с.** Игрок в любой момент видит: кто жив, кто в опасности, что на откате, где телеграф. Всё второстепенное — скрывается.
2. **Пауза — безопасная гавань.** В тактической паузе UI показывает максимум информации: статусы, линии приказов, СЛ проверок. Учим игрока пользоваться паузой через первые три боя (обучающие подсказки).
3. **Диалог — сцена, не меню.** В диалоге UI сжимается до субтитров и портретов; весь мир вне разговора гаснет (виньетка + расфокус).
4. **Ноль модальных ловушек.** Любая панель закрывается той же клавишей, что открыта; Esc всегда открывает/закрывает меню; ни одно действие не блокирует сейв.
5. **Честность проверок.** Сложность проверки видна ДО выбора; шанс успеха показан как «d20 + мод против СЛ» — игрок всегда понимает, чем рискует.

## 3. Игровой HUD (схема раскладки)

```
+------------------------------------------------------------------------------+
| [1] ФРЕЙМ ИГРОКА          [2] ЦЕЛЬ (имя, HP-бар, СЛЗ-подсказка)              |
|  имя | HP ████████░░ | ОВ ██████░░░░ |  LV 7  XP ▓▓▓░░░░░░░░                 |
|  баффы/дебаффы (иконки 4+)                                                   |
|                                                          [3] МИНИКАРТА       |
| [4] ФРЕЙМЫ ОТРЯДА (2)                                     (домен, N, время) |
|  Торвальд HP ████░ ОВ ██░ приказ: [Следовать]          +--------------------+
|  Кайя     HP ███░░ ОВ ███ приказ: [Держать]            |                    |
|                                                          |                    |
|                            (3D-СЦЕНА)                   |                    |
|                                                          |                    |
|                                                          |                    |
| [5] ПАНЕЛЬ УМЕНИЙ 1..7 (иконки, откат-сектора, ОВ-цена)  |                    |
|     [R] зелье (кол-во)   [Q] режим приказа   [Space] ПАУЗА|                   |
| [6] ТОСТЫ/ФЛОАТЕРЫ: броски d20, урон, флаги мира (низ центра, 2 строки)      |
| [7] ПОДСКАЗКА ВЗАИМОДЕЙСТВИЯ: [E] Говорить — Мастер Ямы                     |
+------------------------------------------------------------------------------+
```

Правила поведения: фреймы отряда [4] скрываются вне боя и вне доменов с отрядом; мини-карта [3] сжимается до компаса в диалогах; зона [6] — максимум 2 строки, старые затухают за 2.5 с; полоса босса заменяет блок [2] на весь верхний центр.

## 4. Тактическая пауза (overlay)

- Камера отъезжает в изометрию; мир обесцвечивается на 40% (desat-фильтр), частицы замирают.
- Над каждым союзником/врагом: мини-фрейм (HP, статусы, СЛЗ, тип уязвимости из бестиария — если запись открыта).
- Линии приказов: пунктир от компаньона к цели при заказе атаки; зона удержания — круг на земле.
- Панель приказов внизу: режим отряда, точечные приказы («Умение X по цели Y»), «Отпустить» (Space/Esc).
- Пауза не скрывает опасность: телеграфы АоЕ продолжают тикать визуально (заливка кольца), чтобы решение учитывало время.

## 5. Диалоговое окно

```
+------------------------------------------------------------+
| [ПОРТРЕТ NPC + ИМЯ]              (камера-наезд на говорящего)|
|                                                            |
|   Реплика NPC (1–2 строки, печать текста 25 мс/символ,      |
|   клик — показать сразу)                                    |
|                                                            |
|   > [Проверка: Убеждение 15]  «Мы оба знаем, кто отдаёт     |
|      приказы в этой Яме»            (d20+3 против 15)        |
|   > «Плати сейчас — или узнаешь, что такое тишина.»  [Угроза]|
|   > [Знание: Ямный бой] «Твой левый бок открыт, старик»      |
|   > (Уйти)                                                 |
|  [Таймер 8с ▓▓▓▓▓░░░░░ — только в сюжетных сценах]          |
+------------------------------------------------------------+
```

Проверки подсвечены цветом: успех гарантирован невозможен (всегда d20), цвет рамки — по вероятности (зелёная ≥ 65%, жёлтая 40–65%, красная < 40%). Теги происхождения помечены гербом. Выборы с `silence`-последствием имеют едва заметную глухую иконку — обучение через журнальную статью после первого триггера.

## 6. Ключевые пользовательские флоу

**Флоу A — «Первые 3 минуты» (критично для метрики GDD 00 §7):** титул (2 клика: Новая игра → происхождение) → пробуждение у Разлома (скриптовая сцена ≤ 60 с) → первый шаг управлением (подсветка WASD) → первый бой с 1 волком (пауза-подсказка) → первый знак (Игни) → «вау»-кадр: Разлом вспыхивает эхом шести миров. Без единого текстового туториаль-экрана.

**Флоу B — «Контракт»:** доска в Оплоте → выбор контракта (карточка: цель, награда, сложность) → журнал обновился → приготовление (зелья/масла у костра, состав отряда) → домен: цепочка следов (подсветка E при находке, запись бестиария) → подготовка к бою (масло по типу) → бой/диалог → трофей → возврат: сдача контракта (награда + репутация + возможный флаг).

**Флоу C — «Тренировка»:** разговор с тренером → панель тренера (ветки, LP-цены, требования фракции) → покупка ступени (LP списаны, анимация освоения) → новое умение появляется на панели 1–7 с бейджем «новое».

**Флоу D — «Смерть и возврат»:** HP 0 → замедление ×0.2 на 1.5 с (экран «Тишина звенит…») → экран смерти (точка возврата, потеря 10% золота) → загрузка ≤ 3 с → действие у костра.

**Флоу E — «Финальный рейд»:** стол сборки (6 слотов отряда + роли) → экран снабжения (что дали лояльности/Ключи) → 4 волны → суд (диалог с выборами, таймеры) → концовка + эпилоги компаньонов → титулы.

## 7. Состояния и edge-cases

| Состояние | Поведение UI |
|---|---|
| WebGL2 не поддерживается | Экран-заглушка с текстом и ссылкой на требования (не пустая страница) |
| Контекст WebGL потерян | Автопопытка восстановления; при неудаче — сейв-точка последнего автосейва, сообщение |
| FPS < 45 в течение 5 с | Тост «Рекомендуем пресет ниже» + кнопка применения в один клик |
| Сейв повреждён / версия новее | Сообщение + предложение начать новую игру; тех.детали в свёрнутом блоке |
| Диалог начался в бою | Бой не ставится на паузу (правило мира), но аггро замирает у собеседников-врагов (флаг `peace_talk`) |
| Спутник ушёл (одобрение < −60) | Его слот на панели отряда гаснет с анимацией; фрейм убирается, синергии блокируются |
| Открыто 2+ панелей | Панели взаимоисключающие: открытие новой закрывает прошлую (никаких окон поверх окон) |
| Alt+Tab в паузе | Пауза сохраняется; при возврате — «Отпустить» по клику (защита от случайно зажатого Space) |

## 8. Карта клавиш (сводка; ремап — в настройках)

| Клавиша | Действие | Клавиша | Действие |
|---|---|---|---|
| `W A S D` | движение | `C` | персонаж |
| `Shift` | бег | `I` | инвентарь |
| `ЛКМ` | атака | `J` | журнал |
| `1–7` | умения/знаки | `M` | карта |
| `Space` | такт. пауза | `Esc` | меню/закрыть |
| `Q` | приказ отряду | `E`/`F` | взаимодействие |
| `Tab` | выбор цели | `R` | быстрое зелье |
| `F5`/`F9` | quicksave/load | `H` | скрыть UI |

Конфликт `Q`/`R` из v1.0 устранён: `Q` — только приказы, `R` — только зелье (см. changelog GDD 00 §9).

## 9. Доступность

- Размер шрифта субтитров S/M/L (+30%/+60%); текст на подложке всегда.
- Дальтонизм: полосы статусов дублируются паттернами (полоска/сетка/точки); телеграфы — форма кольца, не только цвет.
- Стрим-режим: скрыть тексты выборов и проверок (анти-спойлер для зрителей).
- Полный ремап клавиш + пресеты «левая рука» (IJKL-схема).
- Звук: отдельные ползунки музыка/эффекты/эмбиент; визуальные дублёры ключевых звуковых сигналов (стадии босса — иконка).
