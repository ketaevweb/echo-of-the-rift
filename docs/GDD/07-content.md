## 6. Реестр флагов мира (конвенция)

Формат: `домен.объект.свойство`, нижний регистр, точка-разделитель, стабильны навсегда (сидируют сейвы и диалоги).

| Флаг | Тип | Что означает |
|---|---|---|
| `world.silence` | число 0–100 | счётчик Тишины (GDD 02 §5.3) |
| `world.shard_truth` | bool | правда осколка известна (SZ-04) |
| `domain.<id>.key_taken` | bool | Ключ-осколок домена получен (6 шт.) |
| `faction.<order|coven|watch>.rep` | число 0–100 | репутация фракции |
| `faction.<id>.member` | bool | членство (карьера GD-02) |
| `companion.<id>.approval` | число −100..100 | одобрение |
| `companion.<id>.loyalty_done` | bool | миссия лояльности завершена |
| `companion.<id>.romance` | bool | романс активен |
| `companion.<id>.gone` | bool | ушёл навсегда |
| `quest.<id>.state` | 0/1/2 | не начат / активен / завершён |
| `choice.<questid>.<n>` | bool/ветка | развилки квестов |
| `npc.<id>.alive` | bool | жив ли ключевой NPC |

Правило покрытия: **каждый `setsFlags` из квеста §1 должен иметь хотя бы одного читателя** (диалог, условие квеста, триггер мира, экономика). Проверяется контент-линтером в CI (GDD 08 §6).

## 7. Концовки и матрица выживания (числа)

Условия 5 концовок — GDD 01 §6. Порядок проверки: Раскол вечности → Тишь → Заря → Печать → Эхо.

**Выживание компаньона в финальном рейде (волны 1–4, MQ-08):**

| Состояние компаньона | Результат |
|---|---|
| Лояльность выполнена + одобрение ≥ 25 | Выживает (гарантированно) |
| Лояльность выполнена + одобрение < 25 | Риск: бросок `d20 + одобрение/10` против СЛ 15 в каждой волне ≥ 2 |
| Лояльность не выполнена | Гибнет на волне, соответствующей его роли (скрипт) |
| Назначен не на свою роль (ошибка игрока) | −5 к броску выживания волны |

**Роли рейда (волна → роль → лучшие кандидаты):** 1 Авангард (Торвальд/Дорн) · 2 Артиллерия (Кайя/Ашер) · 3 Медик/Слово (Мира) · 4 Проводник (Нэри или Ашер). Роль берётся из архетипа; подсказка — в экране сборки рейда (GDD 06 §2, экран финала).

**Эпилоги:** судьба каждого компаньона — 3 варианта (жив-герой / жив-сломлен / погиб) × текст по лояльности и романсу; всего 21 фрагмент эпилога (реестр текстов — задача Фазы 7).
