# GDD 08 — QA: тест-стратегия, ворота и плейтесты

> Пакет GDD «Эхо Разлома» · Документ 8 из 9 · Ворота встроены в роадмап GDD 05

---

## 1. Стратегия (пирамида)

| Уровень | Что | Инструмент | Доля |
|---|---|---|---|
| Юнит | Чистые функции: d20-математика, XP-кривая, LP-цены, веса/токсичность, миграции сейвов | `bun test` | ~60% проверок |
| Интеграция | Шина событий, ECS-порядок систем, квестовые условия/флаги, экономика покупки-продажи | `bun test` + мок-мир | ~25% |
| E2E smoke | Браузерный прогон критических путей по фазам | Playwright-скрипты + ручной чеклист | ~10% |
| Ручной/плейтест | Ощущения, темп, читаемость боя, «вау» | Плейтесты №1–4 + ежедневный smoke | ~5% |

Правило: **всё, что можно проверить юнит-тестом, не проверяется руками.** Числа из GDD 02/07 фиксируются тестами-снимками (snapshot): XP-таблица, цены, HP существ — тест падает при рассинхронизации документа и кода.

## 2. Юнит-тесты (чистые системы)

Обязательный минимум к концу Phase 0:

- **d20-ядро:** детерминированный Rng с сидом; крит 20 = ×2 урон; 1 = провал; модификаторы высоты/фланга/окружения из GDD 02 §2.2; DR-вычитание (минимум 1); полу-крит по оглушённой цели.
- **Прогресс:** XP-формула `80L + 20L²` против таблицы GDD 02 §4.2 (все 20 строк); level-up даёт +10 LP и +2 атрибута; HP/ОВ-формулы.
- **Экономика:** цены с фракционными скидками/наценками; продажа 50%/+30%; вес и лимит `60 + 5×Сил`.
- **Одобрение/тишина:** начисления и пороги GDD 02 §5.3; уход компаньона при повторном −60.
- **Концовки:** функция `resolveEnding(state)` по матрице GDD 07 §7 — табличные тесты на все 5 концовок и граничные значения (silence 40/41, лояльности 3/4).
- **Миграции сейвов:** фикстуры v1→v2, v2→v3; битый сейв возвращает явную ошибку, не падает.

## 3. Интеграционные тесты

- **Шина событий:** `enemy:killed` → XP + счётчик первых убийств + прогресс квеста «убей N» — одна цепочка, один тест.
- **Квестовый движок:** синтетический квест с условиями по флагам/репутации/атрибутам — все ветки прохождения; каждый `setsFlags` реально пишется в сейв.
- **Диалоговое дерево:** проверки с СЛ по актам; провал меняет ветку, не закрывает; таймер-выбор: молчание = третий вариант.
- **Партия:** приказы меняют ИИ-состояние; синергия активна только при одобрении ≥ 60; ушедший компаньон освобождает слот.
- **Магазин/тренер:** списание LP+золота атомарно (нет состояния «LP списан, навык не выдан»).

## 4. E2E smoke-чеклисты (по воротам роадмапа)

**Чеклист A (ворот G0, после Phase 0):**

1. Титул → Новая игра → происхождение → 3D/2D-мир загружен ≤ 5 с.
2. Первый бой: атака, знак, пауза, приказ — работают.
3. Панели C/I/J/M открываются и закрываются той же клавишей.
4. Сейв → загрузка → состояние идентично (HP, золото, позиция, квест).
5. Сейв прототипа v1 открывается с миграцией.
6. `tsc --noEmit` и `bun test` зелёные; lint зелёный.

**Чеклист B (G1, 3D-ядро):** прогулка Оплота в 3D (60 FPS средний ноутбук), коллизии с пропсами, камера не проваливается сквозь рельеф, диалог/бой/панели в 3D-сцене, пресет «Legacy 2D» переключается и работает.

**Боевой регресс (G2):** 8 сценариев — 3 волка (обучение), стрелок на высоте, маг за щитом, окружение 3+, босс-фазы с телеграфами, масло+Игни по слабости, синергия 60+, пауза-стратегия против толпы. Все воспроизводимы в 3D без регресса тактики 2D-прототипа.

**Вертикальный срез (G3):** полный путь титул → MQ-01..04 → Матриарх → тренировка у Дымка; смерть и возврат; автосейвы на входах в домен.

**Флаговый аудит (G6, на каждый домен):** скрипт собирает все `setsFlags`/`requiresFlags` из `data/quests.ts` и диалогов; любые «флаги-сироты» (написан, но не читается) — блокер ворота.

**Матрица концовок (G7):** 8 подготовленных сейвов (Заря/Печать/Эхо/Тишь/Раскол × вариации лояльностей) → все 5 концовок воспроизводятся, эпилоги соответствуют матрице выживания GDD 07 §7.

**Релизный (G8):** все чеклисты + матрица браузеров + перформанс 3 тиров железа + чистые сейвы всех версий.

## 5. Перформанс-QA

- Прогон: сценарий «плотный бой» (8 врагов + 2 спутника + знаки) 90 секунд; метрики: FPS min/avg, frame spikes > 33 мс, draw calls, память текстур.
- Бюджеты из GDD 03 §4 — автопроверка в CI-скрипте (бюджеты = константы кода): превышение — красный прогон.
- Тиры железа: (T1) Intel Iris Xe / 8 ГБ, (T2) GTX 1650 / 16 ГБ, (T3) M-серия / 16 ГБ. Цели: T1 ≥ 45 FPS на «Среднем», T2 ≥ 60 на «Высоком», авто-даунгрейд срабатывает ≤ 5 с при просадке.
- Утечки: 30-минутный прогон домена — память JS ≤ +15% к 5-й минуте (плато), текстурный пул стабилен.

## 6. Контент-линтер (CI)

Скрипт-валидатор пакета `data/` (запуск в CI на каждый коммит):

1. Все ID квестов/существ/предметов уникальны и соответствуют реестру GDD 07.
2. Каждый квест: хотя бы один шаг, награды в пределах ±20% от реестра, `setsFlags` без сирот (см. §4, флаговый аудит).
3. Диалоги: нет тупиковых узлов (у каждого узла есть исходящая ветка или выход); проверки ссылаются на существующие атрибуты.
4. Тренеры: LP/золото-цены совпадают с GDD 07 §4; мастер-ступени требуют репутацию.
5. Числа-снимки: XP-таблица, HP бестиария, цены — сверка с эталонным JSON, сгенерированным из этого документа.

## 7. План плейтестов (4 точки)

| № | Когда | Кто | Главные вопросы | Метрики успеха |
|---|---|---|---|---|
| 1 | После Фазы 3 | 4–6 игроков, 1 ч | Первый «вау» ≤ 3 мин? Понятно следопытство? Баланс L1–5 | «вау»-время ≤ 3 мин у 4/6; Матриарх за 1–3 попытки; никто не застрял в туториале |
| 2 | Фаза 6, домены 1–3 | 4 игрока, 2 ч | Карьера/фракции понятны? Ямные бои азартны? | Выбор лагеря осознан (опрос); LP-дфицит ощущается как выбор, а не famine |
| 3 | Фаза 6, домены 4–5 | 4 игрока, 2 ч | Диалоги без боя держат? Спад темпа Акта II? | Спорные Земли: средняя вовлечённость ≥ 4/5; никто не бросил сессию |
| 4 | После Фазы 7 | 2–3 игрока, полный прогон | 10–15 ч? Концовки честно заработаны? | Полное прохождение в вилке; ≥ 3 разных концовок на группе; матрица выживания сработала |

Ритуал: до — гипотезы (3 шт., записаны заранее); после — опрос из 8 вопросов + тепловая карта смертей; правки баланса фиксируются в GDD 02/07 с датой плейтеста (правило v2.0 из GDD 00 §9).

## 8. Триаж багов

| Уровень | Определение | Правило |
|---|---|---|
| Блокер | Игра не запускается / сейв теряется / квест не завершается | Фаза не закрывается; фикс в тот же день |
| Критический | Поломка боёвки/экономики, обходящий баланс эксплойт | Фикс до QA-ворота |
| Серьёзный | Фича работает криво, есть обход | Бэклог фазы, не позже следующего ворота |
| Мелкий | Косметика, текст, звук | Бэклог релиза (Фаза 8) |

Регресс-политика: каждый закрытый блокер/критический добавляет строку в боевой регресс-набор (G2) или юнит-тест. Правило «двух сессий»: если баг одного класса появляется дважды за две сессии — он становится системной задачей (не точечным фиксом).
