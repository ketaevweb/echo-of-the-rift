## 1. Термины вселенной

| Термин | Определение |
|---|---|
| **Гексмарк** | Шестигранное Ядро, кристалл, на гранях которого «эхили» цивилизации. Центральный артефакт мира. |
| **Эхо** | Отпечаток отзвучавшей цивилизации в Гексмарке. Шесть великих эх = шесть миров-источников доменов. |
| **Раскол** | Катастрофа: Пожиратель треснул Ядро, шесть граней разлетелись и выросли в домены. |
| **Пожиратель Эха** | Антагонист: пустота, питающаяся памятью миров. Не бог и не демон; по сути — то, что осталось от предыдущего Эхорождённого. |
| **Тишь** | Анти-эхо, сочащееся из Разлома. Не убивает, а стирает: краски, имена, память. Измеряется счётчиком `silence`. |
| **Разлом** | Рана в реальности в центре мира; финальная зона (Сердце Разлома). |
| **Эхорождённый** | Игрок: носитель осколка Ядра, единственный, кто слышит все шесть эх и входит в любой домен. |
| **Домен** | Осколок мира вокруг грани Гексмарка: свой климат, народ и правило мира. Семь локаций = 6 доменов + хаб. |
| **Страж Эха** | Босс домена, хранитель Ключа-осколка (шесть штук, кульминации Акта II). |
| **Ключ-осколок** | Фрагмент грани Ядра, забирается у Стража; 6 Ключей нужны для сборки Гексмарка. |
| **Слово** | Сила Криков Пределья: заряжаемые способности с глобальным откатом (Кин, Хаас, Фол, Верен). |
| **Мор** | Стихия Багровой Мары: живой туман, «дышит» и меняет поля боя. |
| **Оплот** | Хаб-поселение у Разлома: тренеры, торговцы, доска контрактов, штаб отряда. |
| **«Двенадцатый»** | Корабль Внешнего Рубежа, брошенный 12 лет назад; база рейд-подготовки Акта III. |
| **Пепельная Матриарх** | Страж Эха Вельда (канон v2.0; раньше встречались «Пепельный Матриарх» и «Пепельная Мать» — не использовать). |

## 2. Термины механик и разработки

| Термин | Определение |
|---|---|
| **LP (очки обучения)** | Редкая валюта прогресса; навыки покупаются только у тренеров за LP+золото (Gothic 2-правило). |
| **XP** | Опыт за квесты/бои/исследования; двигает уровни (таблица GDD 02 §4.2). |
| **d20** | Ядро броска: `d20 + мод против СЛ`; 20 — крит, 1 — провал. |
| **СЛ / СЛЗ** | Сложность проверки / Сложность защиты цели (GDD 02 §2.1). |
| **ОВ** | Выносливость (стамина): бег, атаки, знаки. |
| **DR** | Снижение урона бронёй (плоская величина). |
| **Одобрение** | Шкала −100..+100 отношения компаньона; пороги в GDD 02 §5.3. |
| **Лояльность** | Личный квест компаньона (ME2-паттерн); определяет выживание в финале. |
| **`silence`** | Скрытый счётчик Тиши 0–100; пишется «дешёвыми» решениями, диегетически меняет мир. |
| **Флаги мира** | Ключ-значения сейва, отражающие выборы; конвенция GDD 07 §6. |
| **Тактическая пауза** | Signature-механика: Space → timeScale 0, приказы отряду, изометрический отъезд. |
| **Синергия** | Парный приём игрока и компаньона при одобрении ≥ 60. |
| **Стражи/домены ID** | Стабильные ключи контента (`MQ-01`, `BEAST.wolf_bog`, `domain.veld`) — навсегда (GDD 03 §3.5). |
| **Strangler fig** | Паттерн рефакторинга Phase 0: старый код мигрирует по модулям, сборка всегда играбельна. |
| **IRenderer** | Интерфейс рендер-моста: логика не знает о 2D/3D-бэкенде (GDD 03 §5, шаг 0.8). |
| **QA-ворот (G0–G8)** | Контрольная точка между фазами: smoke + регресс + перформанс (GDD 05, GDD 08 §4). |
| **Painterly PBR** | Арт-стиль: физически корректный свет + живописные текстуры (GDD 04 §1). |

## 3. Канон имён v2.0 (таблица переименований)

Канон закреплён решениями v2.0 (GDD 00 §9). В коде, текстах и диалогах используется только каноническое имя.

| Объект | Канон v2.0 | Запрещённые варианты (v1.0) |
|---|---|---|
| Домен 2 | **Гранитная Долина**; народное имя — **Колония** | «Колония» как официальное имя домена |
| Лагеря Долины | **Пепельный бастион**, **Ветвистый двор**, **Торговый стан** — отделения трёх глобальных фракций | «три отдельных фракции Долины» |
| Арена Долины | **Яма** | — |
| Домен 6 | **Внешний Рубеж** | «Внешняя Рубежа» |
| Босс Вельда | **Пепельная Матриарх** | «Пепельный Матриарх», «Пепельная Мать» |
| Компаньон Торвальд | родом из **Колонии (Гранитная Долина)** | «эхо-домен Колония» |
| Клавиша зелья | **`R`** | `Q` (конфликт с приказами устранён) |
| Клавиша приказа отряду | **`Q`** (цикл режима) + `Tab` (цель) | `Q` = зелье |

**Правило новых имён:** собственные имена существ, NPC и локаций пишутся кириллицей с заглавной; ID в коде — латиницей через точку/дефис по конвенции GDD 07 §6. Каждое новое имя добавляется в этот глоссарий в том же коммите, что и контент.
